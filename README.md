## Dead Focused 👻
A spooky pixel-art Pomodoro timer for staying focused when you'd rather 
be haunting the graveyard.

Dead Focused is a desktop Pomodoro app, built with Python and PySide6, 
featuring original pixel artwork, music and sound effects.

### Features
* Customisable focus and break timers
* Animated pixel-art ghosts
* Adjustable volume
* Play, pause and reset controls

### Why I Built It
Dead Focused was a way for me to combine software development and pixel art
to create a productivity tool that felt more fun than a standard timer.

I love cute and spooky things, so I wanted to bring that aesthetic into the 
app. This led to a little nighttime graveyard scene with ghosts floating 
about while you're trying to focus!
